# 上游代码来源

本仓库用于汇总部署与实验所需代码。以下上游项目的源码、许可证和版权声明均随各自目录保留：

| 目录 | 本地来源 / 上游信息 |
| --- | --- |
| `FAST_LIO_ROS2`、`lidar_localization_ros2`、`ndt_omp_ros2` | 从现有 `fast_lio2_ws` 工作区整理；该工作区原远程地址为 `https://gitee.com/BIT-ROBOCON/mid360-positioning-new-version.git`。 |
| `livox_ros_driver2` | 从现有 `livox_ws` 工作区整理；上游远程地址为 `https://github.com/Livox-SDK/livox_ros_driver2.git`。 |
| `hipnuc_*` | 从现有 `Hipnuc_ws` 工作区中 `hipnuc_ros2/hipnuc_ws/src` 整理。 |

集成仓库中保留了现场相关配置与源码修改，但不宣称拥有第三方上游组件的版权。分发或二次开发前，请分别阅读每个包目录中的许可证。
